Unit 6 · The shape list changes · ~40 minutes

Continuous shape change

A morph target is a second shape the mesh already stores. A weight from 0 to 1 pulls every point toward it. That is not a slide.

3 objectives Sliders + lab 1 homework

What you'll do

In this sitting:

  1. Move a blend weight and say what 0, 1, and halfway mean.
  2. Tell a morph (the points of the shape change) from a matrix move (the whole copy slides, turns, or resizes).
  3. Watch the live morph lab, or drive the flat sliders on this page if you want the motion still.

Lesson

A weight, not an address

Unit 5 kept the corner list and changed the matrix. A morph does the other job. The mesh stores a base shape and one or more targets. A blend weight between 0 and 1 mixes them. At 0 you have the base. At 1 you have that target. At 0.5 each point is halfway along its own path from base to target. The shape’s address on the grid did not have to change. The points inside the list did.

Two weights can be on at once. Each target pulls from the base. If both weights are high, the picture can look stretched. That is the mix, not a broken slider. You are not required to use both.

Weight 0 = base shape. Weight 1 = that target. Weight 0.5 = halfway, point by point. A matrix slide would add the same shift to every point. A morph does not.

The same weights, on a solid

The outline is flat, so a phone can set a weight and hold still. The solid below is one sphere. It stores two other shapes, spike and squash, and it reads the same two sliders. Weight 0 leaves the sphere. Weight 1 is that stored shape. Halfway pulls each point part of the way. You do not drag the solid. The sliders and the buttons are the control.

A slow turn of the whole solid is only so you can tell it is not a flat picture. If motion is reduced, it holds still and the sliders still change the shape. If the solid does not appear, the outline still carries the lesson.

Homework

Write it. If someone is running a section, turn it in there. 160–240 words.

Set one weight on this page. Write the weight you mean (0, 1, halfway, or another value you actually set). Say what the shape was doing — spikes, squash, or a mix — in a sentence a classmate could check by moving the same slider. Then one sentence: why this is not a translation. What would change your mind: the outline at weight 1 matching the plain circle, or the whole shape only sliding with the outline unchanged. If the solid did not start, say so and use the outline. Do not invent a table of weights you did not set.
